# Команды RepoGuard

Список команд выводится из фактического CLI; пояснения принадлежат проектному renderer-у. Этот файл не создаёт прав записи или новой authority требований.

## `build`

Без сетевых вызовов применяет только явные live Projection targets к готовым renderer bytes; orphan cleanup опирается на BASE.

## `check`

Локально проверяет точные BASE/HEAD, Requirement relations, Projection freshness и ownership без записи.

## `check-diff`

Проверяет границы изменения локального Git diff.

## `check-pr`

Представляет оценку PR; применяется лишь в соответствующем адаптере CI.

## `doctor`

Диагностирует наблюдаемые условия самоприменения и конфигурации.

## `init`

Формирует стартовую конфигурацию нового потребительского репозитория.

## `trusted-service`

Исторический операторский режим; не требуется для обычного compiler-only CI.

## `validate`

Проверяет версионированную политику и локальные ограничения репозитория.
