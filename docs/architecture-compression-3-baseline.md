# Историческая база архитектурного сжатия 3.0

Этот файл сохраняет адрес принятой исторической базы, а не задаёт текущие требования продукта. Действующая authority целей находится в [требованиях продукта](product-requirements.md); текущая программа работ — [#518](https://github.com/netkeep80/repo-guard/issues/518).

Базовый коммит измерений: `92432809fcddc290080beb51ba151e13a5761869`. [Полный исторический документ](https://github.com/netkeep80/repo-guard/blob/04c44b3ac7cd5e7e8dc3392144a774f53c5c22b4/docs/architecture-compression-3-baseline.md) сохраняет наблюдения, альтернативы и промежуточные этапы; они не являются новым планом реализации.

```bash
npm run compression:metrics
npm run compression:metrics -- --compare 92432809fcddc290080beb51ba151e13a5761869
```

Метрики наблюдают стоимость, но не доказывают эквивалентность гарантий. Удаление строк ценой нового понятия, слабой диагностики или потери независимой authority не считается сжатием. Текущие ограничения и потребительские контрпримеры важнее исторического плана.
