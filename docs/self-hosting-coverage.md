# Покрытие самопроверкой

`repo-guard` рассматривает самоприменение как проверяемый инвариант и не хранит ручную копию полного списка возможностей.

Самопроверка состоит из двух независимых слоёв.

Первый слой — реальное исполнение собственного репозитория:

- рабочий процесс проверяет свежесть `dist`;
- рабочий процесс запускает метрики сжатия;
- собственная политика исполняется обычной командой;
- `doctor` проверяет операционные предпосылки;
- набор тестов обнаруживается через `tests/run.mjs`;
- готовый PR запускает локальное действие в режиме `check-pr` с блокирующим применением;
- отдельный шаг реально упражняет рекомендательный `check-diff`;
- `smoke-pack` упаковывает, устанавливает и запускает опубликованный интерфейс командной строки.

Второй слой — выводимый инвентарь. Тест `tests/test-c3-4b-self-host-exemplar.mjs` получает команды из `COMMANDS`, семейства исполнения из `defaultRuleFamilies`, встроенные профили из `listBuiltInProfiles()` и сопоставляет их с живым рабочим процессом и честными исключениями.

Файл [`self-hosting-coverage.json`](self-hosting-coverage.json) содержит только исключения. Ссылки вида `command:<id>`, `rule:<id>` и `profile:<id>` обязаны разрешаться в соответствующие живые реестры, а каждое исключение обязано иметь непустое объяснение.

Команда `init` является осознанным исключением: она создаёт стартовое состояние нового потребительского репозитория, поэтому запускать её против уже принятого собственного репозитория ради самоприменения было бы искусственно. Её поведение проверяют специализированные тесты.

Эвристика похожих документов, извлечение якорей, профиль `requirements-strict` и альтернативная форма намерения изменения также остаются честными исключениями там, где искусственное самоприменение ухудшило бы пример вместо усиления доказательства.

Собственная политика не описывает устройство CI отдельным языком. Она хранит только реальные инварианты репозитория, а четыре документных отношения проверяют фактические точки входа пакета и значения по умолчанию действия. Топология исполнения доказывается по живым артефактам, а не вторым манифестом.

Заморозка ядра распространяется и на самопроверку: новая возможность не должна создавать отдельный механизм только ради появления в матрице. Нормальное состояние выводится, вручную фиксируются только неизбежные исключения.
