# Исполняемые сценарии

Этот каталог содержит минимальные примеры использования `repo-guard`, которые одновременно служат регрессионными проверками.

Каждый сценарий является только данными. Тестовый исполнитель создаёт временный репозиторий `Git`, фиксирует состояния `BASE` и `HEAD`, затем запускает настоящий рабочий `CLI`.

```text
examples/scenarios/<scenario>/
  scenario.json
  base/
    repo-policy.json
    <минимальные файлы>
  cases/
    <case>/
      head/
        <наложение поверх base>
```

Файл `scenario.json` содержит только название, краткое описание, команду и ожидаемый результат вариантов. Он не описывает семантику правил и не заменяет `repo-policy.json`.

Правило корпуса простое: данные сценария → реальный переход `Git` → настоящий `repo-guard` → проверка кода завершения и стабильных идентификаторов диагностик.
